multimodel-analysis

Train a set of scikit-learn models on the same train/test split, then get one sorted leaderboard, comparison plots and exportable reports. It covers classification and regression and needs no more than a feature matrix and a target.

$ pip install multimodel-analysis
Classification8 built-in models
Regression8 built-in models
Python3.8 or newer
ExportsCSV, Excel, HTML, JSON

What it does

  • One split, many models. Every model sees the same training and test rows, so the numbers are comparable.
  • Sensible preprocessing. Optional standard scaling that is fitted on the training rows only, automatic label encoding for string targets, stratified splits for classification.
  • Fault tolerant. If one model raises an error it is reported and skipped; the others still run.
  • Reports. A sorted table, confusion matrices, ROC curves, a metric comparison chart (classification) or true-vs-predicted and R² charts (regression), saved as PNG and CSV.
  • Extensible. Pass any scikit-learn-compatible estimator, for example XGBoost or LightGBM, and it is benchmarked next to the built-ins.

At a glance

from sklearn.datasets import load_breast_cancer
from multimodel_analysis import MultiModelClassifier

X, y = load_breast_cancer(return_X_y=True, as_frame=True)

clf = MultiModelClassifier(X=X, y=y, test_size=0.2, scaled_data=True, random_state=42)
results = clf.run_all_models()
clf.show_tabular_report(results)

That prints a table with Accuracy, Precision, Recall, F1 Score and ROC AUC for each model, best first. The measured results section shows the real output of exactly this kind of run.

Quickstart

Both workflows follow the same four steps: build the object, run the models, look at the table, export what you need. The code below is complete and runs as written with scikit-learn's bundled datasets.

from sklearn.datasets import load_breast_cancer
from multimodel_analysis import MultiModelClassifier

X, y = load_breast_cancer(return_X_y=True, as_frame=True)

clf = MultiModelClassifier(X=X, y=y, test_size=0.2, scaled_data=True, random_state=42)

results = clf.run_all_models()                          # 8 models, one split
df = clf.show_tabular_report(results, return_df=True)   # sorted by Accuracy

clf.save_report(df, "classification_report.csv")
clf.get_summary(results, save_prefix="clf", show_plot=False)
# writes clf_report.csv, clf_confusion_matrices.png,
#        clf_roc_curves.png and clf_comparison.png
from sklearn.datasets import load_diabetes
from multimodel_analysis import MultiModelRegressor

X, y = load_diabetes(return_X_y=True, as_frame=True)

reg = MultiModelRegressor(X=X, y=y, test_size=0.2, scaled_data=True, random_state=42)

results = reg.run_all_models()                          # 8 models, one split
df = reg.show_tabular_report(results, return_df=True)   # sorted by R2 Score

reg.save_report(df, "regression_report.csv")
reg.get_summary(results, save_prefix="reg", show_plot=False)
# writes reg_report.csv, reg_true_vs_pred.png and reg_comparison.png

Headless environments

Pass show_plot=False whenever you run on a server, in CI or in a notebook where you only want the files. Otherwise each plot opens through plt.show().

How it works

The whole pipeline lives in one module. Understanding these steps tells you exactly what the numbers mean.

  1. Prepare the target

    The classifier flattens y and runs it through LabelEncoder, so string labels work. The original names are kept in classes_ and used in reports and plots.

  2. Split

    train_test_split with your test_size and random_state. Classification is stratified when stratify=True and every class has at least two samples; otherwise it falls back to an unstratified split without raising.

  3. Scale (optional)

    With scaled_data=True a StandardScaler is fitted on the training rows only and applied to both splits, so no test information leaks into training. With False the raw values are used as they are.

  4. Train and evaluate, one model at a time

    run_all_models() calls each built-in builder in turn, then any custom estimators. Each call is wrapped in try/except; a failure prints a [WARNING] and the loop moves on. Models run sequentially. n_jobs is forwarded only to estimators that accept it.

  5. Collect and report

    Results are kept in models_. show_tabular_report() turns them into a DataFrame sorted best-first, and the plotting methods draw from the same list.

Reading the results

What run_all_models returns

A list with one tuple per successful model. The first item is the display name; the rest is exactly what evaluate_model returned.

ClassTuple layout
Classifier(name, report, matrix, accuracy, precision, recall, f1, fpr_dict, tpr_dict, roc_auc)
Regressor(name, mae, mse, rmse, r2, y_pred)
 
for name, report, matrix, acc, prec, rec, f1, fpr, tpr, auc in results:
    print(f"{name:20s} acc={acc:.3f} f1={f1:.3f} auc={auc:.3f}")

print(results[0][1])   # full classification_report text for the first model

The estimators themselves are not part of the tuple. If you need a fitted model afterwards, build and fit it yourself with clf.X_train_scaled and clf.y_train, or keep the instance you pass in as a custom estimator (it is fitted in place).

How each metric is computed

MetricDefinition in this package
AccuracyCorrect predictions divided by all predictions.
Precision, Recall, F1 ScoreSupport-weighted average over classes (average='weighted', zero_division=0). For binary data this is not the same as the positive-class-only score.
ROC AUCBinary: area under the ROC curve of the positive class. Multiclass: one-vs-rest, support-weighted. NaN if the model has neither probabilities nor decision scores.
MAE, MSE, RMSEMean absolute error, mean squared error and its square root, in the units of the target (squared units for MSE).
R2 ScoreCoefficient of determination on the test split. 1.0 is perfect, 0.0 matches predicting the mean, and it can be negative.

Sorting

The classification table is sorted by Accuracy and the regression table by R2 Score, both descending. With a single small test split, differences in the third decimal are noise; see Limitations.

Useful attributes

AttributeMeaning
X_train_scaled, X_test_scaledFeature splits used by every model (scaled only if scaled_data=True).
y_train, y_testTarget splits. For the classifier these are the encoded integer labels.
classes_, n_classes_, label_encoderClassifier only. Original class labels and the fitted encoder.
models_The latest result list from run_all_models().

Custom estimators

Pass a dictionary of {name: unfitted_estimator} to run_all_models. Anything with scikit-learn's fit and predict works; predict_proba or decision_function additionally gives you ROC AUC. Custom models are appended after the built-in ones and are fitted on the same scaled split.

from xgboost import XGBClassifier
from lightgbm import LGBMClassifier
from multimodel_analysis import MultiModelClassifier

clf = MultiModelClassifier(X=X, y=y, test_size=0.2, scaled_data=True)

results = clf.run_all_models(custom_models={
    "XGBoost":  XGBClassifier(n_estimators=200, learning_rate=0.05, random_state=42),
    "LightGBM": LGBMClassifier(n_estimators=200, learning_rate=0.05, random_state=42),
})
clf.show_tabular_report(results)   # 8 built-ins + 2 custom rows

Labels are encoded for you

The classifier encodes y to integers before training, so XGBoost does not need its own label encoding. A custom model that raises is reported as [WARNING] Custom model '…' failed and skipped.

Exporting reports

save_report picks the format from the file extension. It exists both as a module function and as a method on the classifier and regressor.

ExtensionResult
.csvCSV without the index column
.xlsx, .xlsExcel workbook (needs openpyxl)
.html, .htmHTML table
.jsonJSON array of records
anything elseCSV
 
from multimodel_analysis import save_report

df = clf.show_tabular_report(return_df=True)

save_report(df, "leaderboard.csv")       # module function
clf.save_report(df, "leaderboard.xlsx")  # method with an explicit DataFrame
clf.save_report("leaderboard.json")      # method: reuses the last report
clf.save_report()                        # defaults to report.csv

Passing None or an empty DataFrame prints a warning and writes nothing.

Limitations

        
Knowing what the package does not do matters more than knowing what it does.

        
    
          
  • One split, no cross-validation. Every score comes from a single hold-out set. On small datasets, rankings can flip with a different random_state. Re-run with several seeds before trusting a small gap.
    • 
          
  • Default hyperparameters. The leaderboard compares models as configured, not as tuned. A model that loses here may win after tuning.
    • 
          
  • No preprocessing beyond scaling. There is no imputation, categorical encoding of features or feature selection. Features must already be numeric and free of missing values.
    • 
          
  • Sequential training. Models are trained one after another. n_jobs only parallelises inside estimators that support it.
    • 
          
  • Fitted models are not returned. You get metrics, matrices and predictions, not the estimators. Refit the winner yourself.
    • 
          
  • Plots are fixed. The charts have a fixed design. If you need custom figures, draw them from the result tuples.
    • 
          
  • Weighted averaging. Precision, recall and F1 are support-weighted, which can hide poor performance on a rare class. Read the per-class report text for that.
    • 
        

      


      
      

        
Troubleshooting

        

          

            A model is missing from the table
            
It raised an error and was skipped. Look for a line starting with [WARNING] Model '…' failed in the console. Typical causes are NaN values in X or a non-numeric column.

          

          

            ROC AUC shows NaN
            
The model offered neither predict_proba nor decision_function, or the AUC calculation failed (a warning is printed). It can also happen if a class is missing from the test split.

          

          

            ValueError: Both features 'X' and target 'y' must be provided
            
The constructor needs both arguments. Pass them by keyword: MultiModelClassifier(X=X, y=y).

          

          

            The split is not stratified
            
Stratification is skipped, silently, when any class has fewer than two samples. Check np.bincount(clf.label_encoder.transform(y)).

          

          

            No figure appears, or too many windows open
            
Plots call plt.show() by default. In scripts without a display use show_plot=False and save with save_path or save_prefix.

          

          

            Saving .xlsx fails
            
Excel output needs openpyxl: pip install openpyxl.

          

          

            It is slow on a large dataset
            
Gradient Boosting, Random Forest, SVM and KNN grow quickly with rows. Sub-sample for a first pass. For reference, the 1,797-row digits run on this page took about 12 seconds with ten classes.
